## Contexto Estrategico (Referencia Rapida)

**O que resolve:** Falta de sintese clara do grupo + complexidade percebida externamente

**Para quem:** CEO, CMO, donos de grandes empresas preocupados com relacionamento de todos os publicos

**Diferencial pretendido:**
- Orquestracao de crescimento (territorio proprietario)
- Inteligencia de crescimento adaptativo
- Parceiro que vai alem do diagnostico e entrega solucao

**Territorios a evitar (desgastados):**
- Transformacao digital
- Transformacao de marcas

**Tom desejado:** Pragmatico + proximo + inovador + resultados tangiveis

## Benchmarks (Resumo)

- Accenture Song: robusto + inspiracional. Gap: pesado, distante
- Globant + GUT: moderno + pragmatico. Gap: abstrato para negocios tradicionais
- CI&T: claro + objetivo. Gap: pouco emocional
- Biosphera: contemporaneo + relacional. Gap: confuso na arquitetura
- Galeria: bold + cases. Gap: menos tech e dados

**Brecha para Brivia:** Bold como Galeria + didatico como Biosphera + inovador como Gut + proximo como CI&T
