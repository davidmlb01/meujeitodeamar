# Story 6.1: Spike - Viabilidade GBP Performance API (Dados Geograficos)
**Epic:** DESTAKA-EPIC-003 (Dashboard v2)
**Wave:** 1 - Mapa de Posicionamento Local
**Tipo:** Research/Spike
**Agente:** @architect
**Status:** Draft
**Prioridade:** P0 (bloqueador)

## Objetivo
Verificar se a GBP Performance API retorna dados geograficos (breakdown por regiao, bairro, coordenadas de busca). Documentar campos disponiveis, limitacoes e alternativas.

## Contexto
O Destaka ja tem a GBP Performance API aprovada (quota 300 QPM, projeto GCP 248596818772). O GBPClient em src/lib/gmb/gbp-client.ts ja implementa getPerformanceMetrics() e getSearchKeywords(). Precisamos verificar se existem campos de localizacao nas respostas.

## Acceptance Criteria
- [ ] Documentar todos os campos disponiveis na GBP Performance API relacionados a geografia
- [ ] Testar chamada real com perfil existente e capturar resposta JSON completa
- [ ] Se dados geograficos existem: documentar formato, granularidade e frequencia
- [ ] Se dados geograficos NAO existem: propor alternativa (raio estimado por categoria + reviews + coordenadas)
- [ ] Verificar se Google Places API (ja usada) retorna dados uteis para heatmap
- [ ] Documento tecnico em docs/destaka/spike-geo-api.md com recomendacao final
