## Objetivo
Criar migration para armazenar dados geograficos e endpoint para servir dados ao mapa do dashboard.

## Contexto
Baseado no resultado do spike 6.1, implementar o schema e endpoint adequados. Se API retorna dados reais, armazenar diretamente. Se nao, calcular raio estimado baseado em categoria + coordenadas + reviews.

## Acceptance Criteria
- [ ] Migration criada: tabela geo_snapshots (id, org_id, profile_id, data jsonb, week_start date, created_at)
- [ ] RLS policies configuradas (org_id match)
- [ ] Endpoint GET /api/dashboard/map retornando dados formatados
- [ ] Response shape: { center: {lat, lng}, zones: [{name, status: 'strong'|'medium'|'weak', coords}], radius_km, total_neighborhoods }
- [ ] Tratar caso sem dados: retornar { empty: true, message: "Coletando dados..." }
- [ ] Migration aplicada no Supabase
