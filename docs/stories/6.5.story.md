# Story 6.5: Mapa no Free Tier - Blur + CTA
**Epic:** DESTAKA-EPIC-003 (Dashboard v2)
**Wave:** 1 - Mapa de Posicionamento Local
**Tipo:** Frontend
**Agente:** @dev
**Status:** Draft
**Prioridade:** P0
**Depende de:** 6.4

## Objetivo
Mapa aparece com blur no dashboard gratuito como teaser, visivel completo para assinantes.

## Contexto
O dashboard ja tem logica de free tier com blur (FreeDashboard.tsx, isSubscriber prop em DashboardContent.tsx). Seguir o mesmo padrao.

## Acceptance Criteria
- [ ] Free tier: MapCard renderiza com blur 5px + overlay
- [ ] Overlay: icone de cadeado + "Assine para ver seu alcance completo"
- [ ] CTA: botao "Ver meu alcance" linkando para /dashboard/upgrade
- [ ] Assinante: MapCard renderiza normalmente sem blur
- [ ] Mapa no free tier nao faz chamada a API de dados (economia de recursos)

## Arquivos a modificar
- src/components/dashboard/MapCard.tsx (prop isSubscriber)
- src/app/(dashboard)/dashboard/components/DashboardContent.tsx (passar isSubscriber)
- src/app/(dashboard)/dashboard/components/FreeDashboard.tsx (incluir MapCard com blur)

## Definition of Done
- Free tier ve mapa borrado com CTA
- Assinante ve mapa completo
- Nenhuma chamada de API desnecessaria no free tier
