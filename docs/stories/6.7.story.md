# Story 6.7: Endpoint de Insights de Keywords
**Epic:** DESTAKA-EPIC-003 (Dashboard v2)
**Wave:** 2 - Keywords como Insight Automatico
**Tipo:** Backend
**Agente:** @dev
**Status:** Draft
**Prioridade:** P1
**Depende de:** 6.6

## Objetivo
Endpoint que retorna insights de keywords formatados para o card do dashboard, com linguagem humana.

## Contexto
O card "Como te encontram" precisa de dados processados, nao crus. O endpoint deve calcular tendencias, identificar keywords novas, e cruzar com gaps competitivos (tabela competitive_analyses).

## Acceptance Criteria
- [ ] Endpoint GET /api/dashboard/keywords
- [ ] Response shape:
  {
    total_searches: number,
    trend_pct: number (vs semana anterior),
    top_keywords: [{ keyword, impressions, clicks, is_new: boolean }] (top 5),
    other_count: number (quantas alem do top 5),
    opportunity: { keyword, source: "competitor" } | null,
    week_start: string (ISO date)
  }
- [ ] is_new: true se keyword nao apareceu na semana anterior
- [ ] opportunity: busca gap competitivo da tabela competitive_analyses (keywords que concorrentes tem e o perfil nao)
- [ ] Tratar semana sem dados anteriores: trend_pct = null, is_new = false para todas
- [ ] Tratar perfil sem dados: retornar { empty: true, message: "Coletando dados da primeira semana..." }
- [ ] Auth: requer sessao autenticada
- [ ] .maybeSingle() em todas as queries (padrao Destaka)

## Definition of Done
- Endpoint retorna dados validos para perfil com dados
- Retorna fallback para perfil sem dados
- Zero erros TypeScript
