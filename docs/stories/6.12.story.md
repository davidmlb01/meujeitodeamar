# Story 6.12: Metricas com Contexto - Comparativo Semanal
**Epic:** DESTAKA-EPIC-003 (Dashboard v2)
**Wave:** 3 - Redesign Visual
**Tipo:** Frontend + Backend
**Agente:** @dev
**Status:** Draft
**Prioridade:** P2
**Depende de:** 6.11

## Objetivo
Cada card de metrica mostra valor atual + variacao percentual vs semana anterior com cores semanticas.

## Contexto
Hoje os cards mostram "234 buscas" sem contexto. O cliente nao sabe se isso e bom ou ruim. Adicionar tendencia transforma dado em informacao.

## Acceptance Criteria
- [ ] Backend: endpoint /api/dashboard ja retorna metricas atuais. Adicionar campo previous_period com valores da semana anterior (google_insights table)
- [ ] Frontend: cada MetricCard mostra valor + badge de tendencia
- [ ] Badge: seta para cima + "+X%" em verde (melhorou), seta para baixo + "-X%" em vermelho (piorou), "=" em amarelo (estavel, variacao < 5%)
- [ ] Seta + texto + cor (nao so cor, ACC-004)
- [ ] Se nao houver dado anterior: mostrar so o valor, sem badge
- [ ] 4 metricas: buscas, visualizacoes Maps, cliques no site, ligacoes

## Arquivos a modificar
- src/app/api/dashboard/route.ts (adicionar previous_period)
- src/app/(dashboard)/dashboard/components/DashboardContent.tsx (MetricCard com tendencia)

## Definition of Done
- 4 cards com tendencia visual
- Cores semanticas corretas
- Fallback para primeira semana (sem comparativo)
