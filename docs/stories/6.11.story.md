# Story 6.11: Refatorar DashboardContent - Nova Hierarquia
**Epic:** DESTAKA-EPIC-003 (Dashboard v2)
**Wave:** 3 - Redesign Visual
**Tipo:** Frontend
**Agente:** @dev
**Status:** Draft
**Prioridade:** P2
**Depende de:** 6.10

## Objetivo
Reorganizar o layout do dashboard principal seguindo a hierarquia de 4 niveis do design brief.

## Contexto
Dashboard atual tem componentes soltos sem hierarquia clara. O redesign nao adiciona dados novos, apenas reorganiza o que existe + integra MapCard e KeywordInsightCard.

## Acceptance Criteria
- [ ] Nivel 1 (hero): Score gauge + MapCard lado a lado (desktop), empilhados (mobile)
- [ ] Nivel 2: 4 cards de metricas (buscas, views maps, cliques, ligacoes) em grid
- [ ] Nivel 3: KeywordInsightCard + NextActionsPanel lado a lado
- [ ] Nivel 4: Categorias do score em accordion colapsavel (fechado por default)
- [ ] WeeklyHighlights integrado onde fizer sentido (nivel 2 ou 3)
- [ ] Responsivo: 1 coluna em mobile, 2 colunas em tablet, layout completo em desktop
- [ ] Dark theme mantido, sem mudanca de cores base

## Arquivos a modificar
- src/app/(dashboard)/dashboard/components/DashboardContent.tsx (refatorar layout)
- src/app/(dashboard)/dashboard/components/FreeDashboard.tsx (mesmo layout com blur)

## Definition of Done
- Dashboard com hierarquia visual clara
- Responsivo em 320px+
- Nenhuma feature quebrada
- Zero erros TypeScript
