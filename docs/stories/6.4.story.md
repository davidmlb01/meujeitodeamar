# Story 6.4: Card "Onde Voce Aparece" - Mapa Interativo
**Epic:** DESTAKA-EPIC-003 (Dashboard v2)
**Wave:** 1 - Mapa de Posicionamento Local
**Tipo:** Frontend
**Agente:** @dev
**Status:** Draft
**Prioridade:** P0
**Depende de:** 6.2

## Objetivo
Componente MapCard com Leaflet mostrando heatmap de alcance do negocio, integrado ao dashboard principal.

## Contexto
Briefing CMO define: mapa com zonas verde (forte), amarelo (medio), vermelho (fraco). Copy dinamica baseada nos dados. Nao mostrar grid numerico, nao pedir input do cliente.

## Acceptance Criteria
- [ ] Instalar react-leaflet e leaflet como dependencias
- [ ] Componente MapCard.tsx com dynamic import (ssr: false)
- [ ] Mapa centralizado nas coordenadas do negocio
- [ ] Zonas coloridas: verde (aparece sempre), amarelo (aparece as vezes), vermelho (nao aparece)
- [ ] Copy contextual abaixo do mapa: "Seu negocio aparece em X bairros"
- [ ] Se cobertura boa: "Voce esta bem posicionado na sua regiao"
- [ ] Se areas fracas: "Destaka esta otimizando seu perfil para expandir seu alcance"
- [ ] Responsivo: funciona em mobile (min 320px)
- [ ] Dark theme consistente com dashboard atual
- [ ] Tiles: OpenStreetMap (gratuito) com estilo dark (CartoDB dark_all)
- [ ] Integrado ao DashboardContent.tsx

## Arquivos a criar/modificar
- src/components/dashboard/MapCard.tsx (novo)
- src/app/(dashboard)/dashboard/components/DashboardContent.tsx (integrar MapCard)
- package.json (adicionar react-leaflet, leaflet, @types/leaflet)

## Design Quality Gate
- ACC-001: Contraste >= 4.5:1 nas labels do mapa
- ACC-002: Touch targets >= 44x44px nos controles do mapa
- LAY-001: Sem horizontal scroll em mobile
- TYP-001: Texto >= 16px na copy do card

## Definition of Done
- Mapa renderiza sem erros no dashboard
- Dados reais do endpoint /api/dashboard/map
- Visual consistente com dark theme
- Responsivo em 320px+
- Zero erros TypeScript
