# Story 6.3: Inngest Function - Coleta Geografica Semanal
**Epic:** DESTAKA-EPIC-003 (Dashboard v2)
**Wave:** 1 - Mapa de Posicionamento Local
**Tipo:** Backend/Automation
**Agente:** @dev
**Status:** Draft
**Prioridade:** P0

## Objetivo
Cron semanal no Inngest que coleta dados geograficos da GBP API e armazena snapshots na tabela geo_snapshots.

## Contexto
O Inngest ja tem 8 functions ativas para o Destaka (score-calculator, gbp-audit, review-monitor, post-generator, competitor-monitor, monthly-report, instagram-sync, gbp-optimizer). Esta sera a 9a function.

## Acceptance Criteria
- [ ] Function geo-collector criada em src/lib/inngest/functions/geo-collector.ts
- [ ] Cron: toda segunda-feira as 06:00 UTC (antes do score-calculator)
- [ ] Itera sobre todos os perfis ativos (subscription ativa)
- [ ] Chama GBP API para dados geograficos (ou calcula raio estimado)
- [ ] Armazena snapshot na tabela geo_snapshots
- [ ] Event trigger manual: destaka/geo.collect.requested
- [ ] Registrada no src/app/api/inngest/route.ts
- [ ] Testada com disparo manual

## Arquivos a criar/modificar
- src/lib/inngest/functions/geo-collector.ts (novo)
- src/app/api/inngest/route.ts (registrar function)

## Definition of Done
- Function registrada e visivel no Inngest dashboard
- Disparo manual gera snapshot na tabela
- Logs limpos, sem erros
