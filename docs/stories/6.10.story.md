# Story 6.10: Design Brief - Dashboard v2 Layout

**Status:** Draft

## Objetivo
Design brief com nova hierarquia visual do dashboard, incluindo os cards de mapa e keywords ja implementados.

## Contexto
Briefing CMO define 4 niveis de hierarquia:
- Nivel 1 (hero): Score + Mapa
- Nivel 2 (metricas): 4 cards de performance com tendencia
- Nivel 3 (insights): Keywords + Proximas acoes
- Nivel 4 (detalhes): Categorias do score (colapsaveis)

Principios: cada numero com contexto, cores semanticas (verde/amarelo/vermelho), linguagem do cliente.

## Acceptance Criteria
- [ ] design-brief.md criado em docs/destaka/
- [ ] Layout definido para 4 niveis de hierarquia
- [ ] Especificacao de cores semanticas (verde = melhorando, amarelo = estavel, vermelho = piorando)
- [ ] Tabela de copy: labels tecnicos atuais > linguagem do cliente
- [ ] Especificacao de cards de metricas com mini sparklines ou indicadores de tendencia
- [ ] Categorias do score: colapsaveis por default
- [ ] Responsivo: breakpoints definidos (320px, 768px, 1024px+)
- [ ] Dark theme mantido
