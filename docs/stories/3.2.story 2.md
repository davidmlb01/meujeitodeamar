## Contexto

LeadsQualityScorer foi implementado em EASYSITE-3.1 como classe standalone. Agora precisa ser integrado na arquitetura EasySite:

```
Leads (54 no Campinas)
  → Prospecção automática (bot v2.0)
  → LeadsQualityScorer (EASYSITE-3.2)
  → Ranking por score
  → Recomendação de ação (ligar imediatamente / nurture / arquivar)
```

**Scoring Model:**
- Engagement (40%): tempo página, cliques, scroll, forms
- Profile (30%): localização, device, categoria negócio
- Temporal (20%): recência exponencial + frequência retorno
- Source (10%): canal origem, performance campanha, variant AB

**Weights:**
- Location: Recife 1.0, default 0.6
- Device: desktop 1.0, mobile 0.7, tablet 0.8
- Category: saúde 1.0, jurídico 0.95, pet 0.9, default 0.5
- Channel: TikTok 1.0, Instagram 0.8, YouTube 0.7, organic 0.6

**Saída:**
- Score (0-100)
- Grade (A-F)
- Recommendation (text)
- Individual scores (engagement, profile, temporal, source)
