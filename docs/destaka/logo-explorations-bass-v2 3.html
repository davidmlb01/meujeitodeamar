Três direções. Uma escolha.

Cada exploração reduz o conceito Pin+Olho (localização + visibilidade) a uma forma diferente. A recomendação é a B: mínima, inevitável, funcional em qualquer escala.

A. Geométrico
Olho completo com íris e pupila. Mais detalhado. Perde legibilidade abaixo de 32px.
Recomendada
B. Redução Máxima
3 elementos. Nada pode ser removido sem perder significado. Funciona de 16px a outdoor.
C. Fusão Olho-Pin
O olho é o pin. Forma horizontal, conceito ousado. Exploração conceitual.
