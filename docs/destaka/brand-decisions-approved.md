# Destaka: Decisoes de Marca Aprovadas
## Aprovado por David em 2026-05-06

### DECISAO 1: Tipografia
**Opcao B aprovada: Plus Jakarta Sans + Fraunces**

| Uso | Familia | Pesos | Tracking |
|-----|---------|-------|---------|
| Headlines/Display | Fraunces (serif variable) | 600-700 | -0.02em |
| Corpo/UI | Plus Jakarta Sans | 400, 500, 600, 700 | normal |
| Dados/Mono | JetBrains Mono | 400 | normal |
| Fallback | system-ui, -apple-system, sans-serif | - | - |

### DECISAO 2: Mark
**Direcao C aprovada: Janela/Moldura (container geometrico)**

- Mark como container geometrico (quadrado com recorte ou abertura)
- Conceito: "ser colocado em destaque", "vitrine digital"
- Escalavel: mesma moldura, cor por vertical
- Funciona como: simbolo sozinho, container para icone, container para foto
- Explorar tambem Direcao A (Ponto de Luz) como fallback
- Saul Bass lidera criacao, Paula Scher valida tipografia ao redor

### DECISAO 3: Fotografia
**Hibrido aprovado: foto real (externo) + ilustracao (interno)**

| Contexto | Abordagem | Estilo |
|----------|-----------|--------|
| Landing, ads, social | Fotografia real | Profissional no ambiente, luz natural, diversidade |
| Dashboard, app, UI | Ilustracao minimalista | Line art monocromatico na cor da vertical |
| Social media | Mix | Dado + foto (educativo), screenshot + badge (resultado) |
