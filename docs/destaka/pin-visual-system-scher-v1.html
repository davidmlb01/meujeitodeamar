Direção 01

Geometria Base — Desconstrução

O símbolo é formado por 3 primitivos. Cada um carrega significado autônomo. Separar para entender o que pode virar sistema.

01 — O Pin
Forma de gota. Identifica localização. Carrega sozinho a ideia de "encontrar" sem o olho interno. Funciona como bullet, marcador, separador.
02 — A Íris
Oval horizontal negativo. Forma de olho. Separado do pin, vira ícone de visibilidade, monitoramento, observação — sem precisar do pin.
03 — O Núcleo
Círculo sólido central. Ponto focal, origem. Vira avatar, marcador de passo ativo, indicador de status em UI.

Insight de desconstrução

  • Cada primitivo carrega valor semântico autônomo — um sistema bem projetado não precisa do logo inteiro para comunicar.
  • A íris oval é o elemento mais diferenciado: nenhum concorrente de GMB usa um "olho" como metáfora de visibilidade.
  • O núcleo como "ponto ativo" tem aplicação direta em UI: steps, progress indicators, status de perfil.
Direção 02

O Pin como Padrão — Repetição e Textura

O mesmo símbolo repetido em sistema gera identidade antes do nome. Três variações: grid denso, dispersão orgânica, orientações alternadas.

Grid Denso
Fundo de seções premium. Identidade pré-logo.
Dispersão Orgânica
Slides, capas de apresentação, backgrounds hero.
Orientações Alternadas
Textura de tecido, swag, impressão offset.

Diagnóstico de escala

  • Abaixo de 16px: o olho interno some. Fica como teardrop puro — ainda reconhecível.
  • 16px a 48px: os 3 elementos visíveis. Janela principal de uso em produto.
  • Acima de 96px: detalhe da íris oval fica evidente. Funciona como hero element em landings.
  • OOH (outdoor): o pin ampliado sem wordmark identifica a marca — teste para próxima etapa.
