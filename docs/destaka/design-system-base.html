Destaka. Design System Base Tokens v1.0

Design System
Base

Documento tecnico com todos os tokens compartilhados, especificacoes de componentes e regras de tematização que se aplicam a todos os verticais da plataforma Destaka. Temas de verticais sobrescrevem apenas os tokens de acento.

01 / Cores

Sistema de Tokens

Abordagem B: fundo neutro escuro (#0F1117) em toda a interface do produto. O acento de cada vertical é a única cor cromática, garantindo vibração e contraste máximos. O verde profundo #0F2A1F é reservado para materiais institucionais da marca (logotipo, brandbook, cartão de visita, site hub). Todos os tokens de cor são definidos como CSS custom properties no :root. Verticais sobrescrevem apenas as variáveis --accent-*.

Temas por Vertical

Overrides de Acento

Cada vertical sobrescreve apenas três tokens. Todos os demais tokens (background, text, border, spacing, tipografia) permanecem idênticos. Sobre fundo neutro #0F1117, cada acento atinge vibração e contraste máximos, funcionando como a única cor cromática da interface.

Nota sobre #0F2A1F: Verde profundo #0F2A1F é a cor institucional da marca Destaka. Aparece em: logotipo, brandbook, materiais impressos, cartão de visita, site institucional (hub). NÃO aparece como fundo de interface do produto. A interface usa exclusivamente o fundo neutro #0F1117, onde cada acento de vertical brilha como única cor cromática.

09 / Tematização

Como Tematizar

Verticais sobrescrevem apenas os tokens --accent-*. Todo o resto do design system permanece identico. Use o atributo data-vertical no elemento raiz.

Regra fundamental: um tema de vertical nunca modifica tokens de background, texto, borda, tipografia, espaçamento, radius ou sombra. Apenas as cinco variaveis de acento mudam.
Codigo
